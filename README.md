# TouchClick — "Un click. Tu mente en calma."

Landing page interactiva y maqueta funcional de e-commerce desarrollada para **TouchClick**, un proyecto estudiantil creado por *La Infalible*. 

TouchClick es un accesorio sensorial portátil (banda de silicona con switch mecánico intercambiable y llavero) diseñado para acompañar momentos de estudio, concentración y descanso mediante estímulos táctiles y auditivos.

##  Características del Proyecto
- **100% Vanilla:** Desarrollado exclusivamente con HTML5, CSS3 moderno y JavaScript (sin dependencias ni frameworks).
- **Diseño Responsive:** Adaptado para dispositivos móviles, tablets y pantallas de escritorio.
- **Simulador Interactivo:** Tecla/switch mecánico interactivo con feedback visual.
- **Flujo de Compra Simulado:** Catálogo de productos, personalización, carrito con persistencia local (`localStorage`) y checkout ficticio.
